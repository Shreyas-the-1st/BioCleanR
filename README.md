# BioCleanR 🧬

*The name is pronounced Bio-Cleaner. Yes, I know.*

## What is BioCleanR?

The idea behind this project is pretty simple: create an R program that takes a biological dataset, cleans it up, and makes the resulting data a lot easier for humans to actually read and understand.

In a sense, BioCleanR is meant to take raw biological data and turn it into something more organised, readable, and eventually easier to visualise.

Biological datasets can get pretty messy. Missing values, inconsistencies, duplicates, and all sorts of formatting issues can make working with raw data a bit of a headache. This project aims to make that process easier.

## What am I trying to achieve?

The goal is to develop a program that can:

- Import raw biological datasets provided by the user.
- Identify potential quality issues within the data.
- Clean and organise the dataset.
- Make the processed data easier to interpret.
- Prepare the data for simple visualisations.

Eventually, I'd like BioCleanR to support different kinds of biological datasets rather than being restricted to just one particular type.

## The Technology

As you could probably guess by now, R is going to be the backbone of this project.

- **Language:** R
- **Field:** Bioinformatics / Biological Data Processing
- **License:** Open source (to be decided)

## Current Progress
